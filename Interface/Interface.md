The Interface settings allow you to customize the visual appearance and behavior of your Flipper Zero. These settings can be found by pressing `UP` on the Desktop and navigating to `MNTM > Interface`.

## [Graphics](Graphics)

Customize animations and visual themes through Asset Packs:

- [`Asset Pack`](Graphics#Asset-Pack): Load custom animations, icons, and fonts
- [`Animation Settings`](Graphics#Animation-Settings)
  - [`Anim Speed`](Graphics#Anim-Speed): Control playback speed (25-300%)
  - [`Cycle Anims`](Graphics#Cycle-Anims): Set animation change intervals
  - [`Unlock Anims`](Graphics#Unlock-Anims): Toggle special unlock effects

## [Main Menu](Mainmenu)

Configure your main menu appearance and content:

- [`Menu Style`](Mainmenu#Menu-Style): Choose from 9 different menu layouts
- [`Menu Management`](Mainmenu#Menu-Management)
  - [`Reset Menu`](Mainmenu#Reset-Menu): Restore default configuration
  - [`App Management`](Mainmenu#App-Management): Add, remove, and arrange apps

## [Lock Screen](Lockscreen)

Set up security and lock screen behavior:

- [`Lock on Boot`](Lockscreen#Lock-on-Boot): Controls whether your Flipper locks automatically when powered on
- [`Format on Bad PINs`](Lockscreen#Format-on-Bad-PINs): Automatically formats device after 10 incorrect PIN attempts
- [`Allow USB RPC while locked`](Lockscreen#Allow-USB-RPC-while-locked): Control USB connectivity while locked
- [`Allow BLE RPC while locked`](Lockscreen#Allow-BLE-RPC-while-locked): Control Bluetooth connectivity while locked
- [`Allow Poweroff`](Lockscreen#Allow-Poweroff): Control power options while locked
- [`Lockscreen Elements`](Lockscreen#Lockscreen-Elements): Configure info and visual elements on the lockscreen

## [Status Bar](Statusbar)

Customize the top status bar:

- [`Battery Icon`](Statusbar#Battery-Icon): Choose battery display style
  - [`Battery Styles`](Statusbar#battery-styles): Available battery styles
- [`Show Clock`](Statusbar#Show-Clock): Toggle time display
- [`Show Icons`](Statusbar#Show-Icons): Toggle status icons
  - [`Status Icons`](Statusbar#status-icons): Table of all status icons and their meanings
- [`Bar Borders`](Statusbar#Bar-Borders): Toggle border around statusbar elements
- [`Bar Background`](Statusbar#Bar-Background): Toggle statusbar "ribbon cable" design background

## [File Browser](File-Browser)

Adjust file browsing experience:

- [`Display Options`](File-Browser#Display-Options)
  - [`Folders Above Files`](File-Browser#Folders-Above-Files): Sort directory display
  - [`Show Hidden Files`](File-Browser#Show-Hidden-Files): Toggle hidden file visibility
  - [`Show Internal Tab`](File-Browser#Show-Internal-Tab): Toggle internal storage
  - [`Show Path`](File-Browser#Show-Path): Configure path display
- [`Favorite Timeout`](File-Browser#Favorite-Timeout): Set quick-access menu duration

## [General](General)

Settings that apply generally to the flippers look and feel.

- [`Text Scroll`](General#Text-Scroll): The scroll type for all overflow text (Archive, Main Menu, Settings, etc.).
- [`Clock Midnight Format`](General#Clock-Midnight-Format): How the clock displays 12 AM.
